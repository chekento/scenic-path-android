# GitHub APK release channel

The Scenic Path repository publishes the installable RC/debug APK as a GitHub Release asset.

- Tag: `v0.6.2-rc1`
- APK: `Scenic-Path-v0.6.2-rc1-debug.apk`
- Checksum: `Scenic-Path-v0.6.2-rc1-debug.apk.sha256`
- Package: `cloud.kosch.scenicpath`

The repository frontpage hero graphic links directly to the APK asset. The release workflow also stores the same files as a GitHub Actions artifact for build traceability.
